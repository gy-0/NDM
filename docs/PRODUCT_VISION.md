# 产品愿景：不是下载器，是 Mac 上的下载收件箱

> 工作名 Pelican。产品承诺：**把任何下载线索交给它，得到一个马上能用的文件。**

## 1. 产品判断

强大的下载引擎只是入场券，不是用户付费的最终理由。用户真正购买的是三件事：

1. **不用研究**：不用分辨直链、网页、m3u8、分享口令，也不用认识 yt-dlp、ffmpeg、Cookie 或音视频分轨。
2. **不用担心**：软件会说明现在在识别、等待站点、下载、合并还是整理；失败时告诉用户下一步，而不是丢出日志。
3. **不用收尾**：文件命名正确、封面可见、字幕同名、容器兼容、位置清楚，下载结束就是交付完成。

因此我们不做“功能更多的 NDM”，而做一个从输入到交付都闭环的 **Download Inbox**。

## 2. 三个必须让人记住的 Magical 时刻

### 2.1 Paste Anything：扔进来就懂

用户可以粘贴：

- 文件直链；
- YouTube、B 站、抖音、小红书等视频页面；
- 带标题、表情、口令和时间戳的整段分享文本；
- 浏览器捕获的媒体；
- 拖到窗口或菜单栏图标上的链接和文字。

软件立即给出站点身份和“我理解你想下载什么”，自动抽取真正链接。用户不需要先清洗输入。

实现已经形成完整入口闭环：`SharedLinkResolver` 会从抖音、小红书、B 站、YouTube 等分享文本中摘取并优先选择媒体链接；`ShortLinkExpander` 会用不读取 Cookie、不留缓存的临时会话展开抖音、小红书、B 站、YouTube 与 TikTok 常见短链。新建下载、主窗口拖放和菜单栏拖放共用同一输入规则，短链失败则安全回退原地址。

Magic Inbox 把“已经能读懂”变成“不需要再找入口”：用户在抖音、小红书、B 站、YouTube 或 TikTok 复制链接/分享口令后切回软件，第三版顶部工具带的留白中会出现一条来源明确的扁平操作，例如“下载抖音分享”。它不生成通知气泡、不弹窗抢焦点、不在后台自动开下；点击后进入原有 Link Lens，继续享受重复识别、空间保护、偏好记忆和 Ready Choice。剪贴板只在软件激活时、`changeCount` 变化后本地读取一次，开关关闭时候选立即消失。

### 2.2 Calm Progress：复杂，但看起来很安静

进度不是两根互相打架的百分比，而是一条可信的交付时间线：

`正在识别 → 准备下载 → 下载视频/音频 → 合并 → 整理 → 可以使用`

设计原则：

- 总进度表示“距离可用文件还有多远”；分段只解释连接工作，不与总进度竞争。
- 站点解析慢时立即出现明确阶段和可取消操作，不让用户误以为按钮没生效。
- 离散进度数据通过平滑动画呈现，但不伪造速度或百分比。
- 多连接没有收益时自动收敛，并用一句人话解释。

### 2.3 Smart Delivery：下载完成不是终点，交付完成才是

Smart Finalize 应从“完成弹窗”升级为产品核心：

- 自动得到适合 Mac、QuickTime、iPhone 和主流播放器的容器；
- 视频、字幕、封面和元数据作为一个下载成果展示，不在列表里散成四个任务；
- 字幕与视频严格同名；多语言字幕使用播放器能识别的语言后缀；
- 自动清理站点尾巴、随机 ID、追踪参数和重复后缀；保留合集序号，重名使用 Finder 风格编号且绝不覆盖；
- 主文件改名时，同步迁移同名字幕、封面、音轨与元数据；完成页只陈述磁盘上真实发生的整理；
- 默认只提供高频结果：“保留原文件”与“只要音频”；低清转码和聊天软件压缩不占据核心界面；
- 文件已存在、磁盘空间不足或合并失败时，保留原始成果并给出安全选择。

## 3. 产品能力架构

### A. 输入智能

- 分享口令解析与链接优先级；
- 短链展开和重定向预检；
- 浏览器一键接管、拖放、剪贴板感知；
- 站点图标、标题、封面和内容类型的即时反馈。

### B. 兼容性阶梯

每个输入依次走下面的能力，而不是给每个网站写一套 UI：

1. 通用 URL / 文件探测；
2. yt-dlp 站点提取器；
3. 浏览器会话接力（用户明确选择一个已经能打开该页面的浏览器）；
4. 浏览器捕获到的真实媒体请求；
5. 失败诊断与可执行恢复操作。

产品可以说“支持大量主流站点”，但不宣传“全网万能”。站点变化时要诚实、可恢复、可更新。

发行包把这条阶梯需要的 yt-dlp、FFmpeg 与 Deno 作为私有、已签名的工具链一起交付；Release
不会从 Homebrew 或 PATH 偷偷兜底。打包门禁会在清空环境变量后启动 App 自检，真实网络烟测还会
完成公开视频探测、播放列表解析和小文件下载。因此普通用户安装一个 App 即可使用核心视频能力，
界面和错误文案也不会要求用户认识或安装这些底层组件。

### C. 下载编排

- 普通文件多连接、FTP、HLS、分轨媒体自动路由；
- 智能连接、断点续传、队列、限速和代理；
- 重试已完成任务时真正覆盖或生成新副本，不假完成；
- 预估最终体积，并在 4K/8K 下载前检查磁盘空间。

### D. 交付与整理

- Smart Finalize；
- 按来源、类型、项目或用户规则自动归档；
- 重复下载识别；
- 来源、画质、字幕和交付配方可回看；
- Finder、播放器、分享和复制来源都在同一成果页完成。

首版分享闭环已经落地：已完成任务的详情页保持三段式扁平动作栏，把“分享”提升为直接动作；低频的复制来源、属性和移除收进同一处更多菜单。完成弹窗也提供标准系统分享入口，直接把真实主文件交给 AirDrop、信息、邮件或用户安装的分享服务，不自行上传、不悄悄压缩，也不把字幕和封面散成一包意外附件。

## 4. 让人愿意付费的功能边界

免费版必须足够好，用户先相信产品；Pro 购买的是节省时间和高级交付，不是解除人为制造的痛苦。

### Free

- 普通文件与主流单视频下载；
- 4 条连接；
- 基础画质和 MP4 自动交付；
- 暂停、续传、诊断和 Finder 操作；
- 本地处理、无广告、无需账号。

### Pro

- 最高 32 条连接与高级调度；
- 4K/8K、HDR、音轨和多语言字幕；
- 播放列表、合集、频道和批量任务；
- Smart Finalize 配方、自动分类和分享导出；
- 浏览器会话接力、站点恢复工具和高级规则；
- Shortcuts / Raycast 自动化；
- 一段时间内的兼容性与功能更新权益。

购买触发应发生在用户已经看到价值的时刻，例如选择 4K、导入播放列表或保存自动化配方时；不做开屏拦截和频繁弹窗。

首版付费触发已经按这个原则落地：用户选择超过 4 条连接、4K/8K、整合集或字幕后，
升级页先解释“这一次 Pro 会替你完成什么”，而不是先扔出一张套餐对比表；许可证激活成功后会自动继续刚才的操作。

## 5. 值得做、但不能同时做的亮点

### Link Lens

粘贴后先出现一个很轻的内容预览：站点、标题、封面、时长、预计体积，以及“推荐交付结果”。复杂格式仍可展开，但默认只需要一个主按钮。

首版已经接入新建下载入口：站点身份会在粘贴后立即出现，真实标题、封面、时长、画质档位和字幕概况在后台渐进补齐。预览不构成下载门槛，用户可以随时继续；完成或仍在进行的探测会由下一步画质选择直接复用，因此不会重复等待。需要浏览器会话的页面仍在继续后进入既有的人话引导，入口不提前暴露底层工具或原始错误。

### Collection Lens

播放列表、课程、频道或合集不能退化成“一不小心只下载了其中一个视频”。首版在 Link Lens 中同步识别合集标题、封面与条目数；画质页沿用同一条扁平选择器，让用户选择当前视频或整合集。整合集会拆成带顺序编号的独立任务，按顺序安静运行，单项失败后继续后续项目，重启软件也会恢复队列。超长合集首轮只准备前 100 项并明确说明，不制造“整个合集已经全部加入”的假象。

### Already Here

重复下载不应该在任务创建以后才靠文件重名暴露。Link Lens 会在识别内容的同时查找本地下载收件箱：YouTube、B 站、抖音、小红书和 TikTok 等页面优先按稳定内容 ID 匹配，普通文件链接只忽略明确的分享追踪参数，签名和授权参数仍保留，避免误判。找到已有任务后，用户可以直接回到原任务及其 Inspector，也可以明确选择“再下载一份”；产品不弹阻断警告，也不偷偷替用户取消。播放列表保留自己的合集身份，不会因为首条视频已存在就误报整合集重复。

### Delivery Recipes（已收敛）

用户保存“下载后我要什么”，而不是保存 ffmpeg 参数：

- 保留原文件；
- 只要音频。

首版曾把原画 / 手机 / 音频 / 微信四个结果同时放进成果页。实际产品判断后已收敛为原文件 / 音频两个高频结果：避免把罕见的 1080p→720p 和“微信压缩版”包装成核心价值。兼容与聊天压缩能力暂留在引擎层，供未来明确场景调用，但默认界面不再展示。

### Preference Memory

画质页应该越用越懂用户，而不是每次把选择题重新出一遍。用户在某个站点真正开始下载时，软件只在本机记住画质高度、MP4/MKV 与字幕语言；下次同站点探测完成后直接恢复这套交付偏好，不增加设置页、规则编辑器或“已学习”徽章。若当前视频没有该画质或字幕，则回到产品推荐画质并关闭不可用字幕。记忆只按规范化站点保存，不记录页面链接、标题、Cookie、内容 ID 或浏览历史。

### Continuity Progress

用户只应该看到一次从 0 到 100 的旅程。在线视频的真实字节和最终成品进度分开记录：字节可以在下载结束时诚实显示 100%，但蓝色主进度、绿色细进度、列表、Inspector 与 Dock 共用同一条单调的成品进度。底层通过结构化 postprocessor 事件区分音视频合并、字幕整理和最终文件准备，不再靠日志文案猜测，也不再出现视频 100% 后音频从 0% 重跑、两条进度不同步或成品已经存在仍显示“正在合并”。只有可打开的最终文件落盘后才显示 100%。

### Ready Choice

记住偏好只是第一步，真正的收益是下一次少做一步。单个媒体完成预览后，如果该站点上次确认的画质、容器与字幕在当前内容中全部精确存在，而且 Space Confidence 明确为充足，Link Lens 直接把唯一蓝色主操作写成“下载 1080p · MP4”，旁边保留一个安静的“选项…”入口。点击主操作复用原任务创建、空间校验、进度和完成交付路径，并不会走一条脆弱的快捷分支。画质或字幕不存在、空间紧张/未知、合集、重复下载、浏览器授权等任何不确定状态都回到完整画质页；这里的一键来自确定性，不来自替用户猜测。

### Completion Stack

一个视频及其字幕、封面、音轨在列表里始终是一个成果。展开后才看组成文件，避免下载管理器变成临时文件垃圾场。

首版已经落地在完成窗口和原地完成的进度窗口：主文件仍是唯一主角；同名字幕、封面、独立音轨和元数据会被保守识别为附属文件，默认折叠，展开后可逐个在访达中显示。在线视频任务也会按可播放媒体呈现，而不再落回普通文件完成态。展开时窗口按实际文件行数平滑增高并保持顶部位置，避免内容被压缩或裁切。

### Link Rescue

链接过期时，从原网页或浏览器会话重新取授权并继续现有分段；用户看到的是“链接已刷新，继续下载”，不是重新开始。

首版闭环已经落地：对明确的链接过期或登录失效任务，主窗与进度窗优先打开原来源页；浏览器随后捕获到同一页面的新下载地址时，宿主不会创建重复任务，而是把 URL、Cookie、Referer、User-Agent 与可选音轨重新接到原任务，保留任务 ID、目标文件名和所有已落盘分段。双轨媒体只有在视频、音频都拿到新地址时才恢复，避免新旧授权混用；没有可靠来源页的普通直链仍保留手动粘贴新地址的退路。已完成的视频任务重试则明确清除旧分段并强制重新下载，不再瞬间假完成。

### Magic Drop

菜单栏图标成为全局投递口。拖入链接、选中文字或整段口令后，出现短暂的站点身份反馈，随后安静进入下载收件箱。

## 6. 反功能清单

- 不把 yt-dlp、ffmpeg、aria2 或命令行术语展示给普通用户；
- 不用播放按钮暗示并不存在的播放能力；
- 不用无意义的大卡片、徽章和动画假装高级；
- 不把基本视频下载做成必须登录云账号；
- 不默认上传用户链接、Cookie、文件或历史；
- 不承诺绕过付费墙、DRM 或网站权限；
- 不为了“支持更多”让失败路径变得沉默和不可理解；
- 不在第一版同时做 Windows、移动端和资源社区。

## 7. 接下来三场战役

### 战役一：入口零摩擦

- 万能粘贴首版；
- ~~短链展开~~ ✅ 常见社交短链先安全展开，失败不阻断；
- ~~受限站点的引导式浏览器接力~~ ✅ UI 不出现 Cookie 或命令行术语；
- ~~新建下载中即时显示站点、内容和下一步~~ ✅ Link Lens 首版，预览不阻塞并与画质选择复用同一探测。

成功标准：用户复制整段分享文本后，不编辑任何字符即可进入画质选择或下载。

### 战役二：交付可信

- 统一总进度阶段；
- ~~完成成果成组~~ ✅ Completion Stack 首版；
- ~~同名字幕~~ ✅；容器兼容继续完善；
- ~~Smart Finalize 配方首版~~ ✅ 已收敛为原文件 / 音频；后续只在真实需求成立时扩展，而不是继续堆预设。
- ~~Smart Naming~~ ✅ 视频/音频落盘后安全改名，附属文件跟随迁移，冲突不覆盖，完成文案与实际文件一致。
- ~~Share-ready Handoff~~ ✅ 详情页和完成页直接调用系统分享，复制来源仍可达，默认只交付主文件。

成功标准：下载结束后，用户第一次打开就能播放，第一次分享就能发出去。

### 战役三：付费闭环

- 真购买页、恢复购买、更新权益；
- 在 4K、批量、配方、32 连接等高价值时刻触发；
- 记录本地、隐私友好的漏斗：识别成功、下载成功、交付成功、Pro 触发和购买。

成功标准：用户能清楚说出 Pro 为自己节省了哪一步，而不是只知道“免费版被限制了”。

## 8. 产品北极星

核心指标不是峰值下载速度，而是：

> **从用户投递内容到得到可直接使用文件的成功率与中位耗时。**

辅助指标：

- 分享文本无需编辑的识别成功率；
- 首次下载完成率；
- 完成后 60 秒内打开 / Finder / 分享的比例；
- 因 Cookie、链接过期、磁盘或合并失败而流失的比例；
- Pro 触发后，用户是否刚刚使用了一个真实高级价值点。
