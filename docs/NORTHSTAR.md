# 北极星与每日开发循环

> 决策日期：2026-07-24
> 当前阶段：**打磨核心功能 + 建立差异化护城河**。命名、图标、支付、官网明确后置，不在本阶段消耗精力。

## 0. 北极星指标

沿用 `PRODUCT_VISION.md` 第 8 节：

> **从用户投递内容到得到可直接使用文件的成功率与中位耗时。**

关键事实：这条指标至今**没有测量工具**。307 个单元测试覆盖的是逻辑正确性，不是真实世界成功率。P0-2 就是补这个洞。

## 1. 硬约束（每一轮都必须遵守）

- **测试源不使用国外 CDN。** 真实下载测试使用国内可达源（例如 `qqdl.gtimg.cn` 的公开安装包）。国外源的失败无法区分"我们的 bug"和"网络"。
- **不向用户暴露 yt-dlp / ffmpeg / deno / 命令行术语**，见 `PRODUCT_VISION.md` 第 6 节反功能清单。
- **不默认上传用户链接、Cookie、文件或历史。** AI 能力优先本地推理；任何需要联网的推理必须是用户显式开启的可选项，且在 UI 上说明数据去向。
- **完成页只陈述磁盘上真实发生的事。** AI 生成的命名、摘要、章节只能是**建议**，不能静默改写用户文件。
- **设计遵循 `design/brand-spec.md` 与既有硬规则**：不要灰色色块/灰底、按钮 28pt 自然宽度、hero 数字用 light 字重、CJK 文件名截断。

### P1 · 差异化：从"下载器"变成"素材库"

核心判断：**用户下载视频的真实目的，往往是要里面的信息，不是要那个文件。** 谁先把"下完 → 能读 → 能搜"闭环，谁就不再是下载器竞品，而是另一个类目。

| # | 事项 | 已有基础 | 说明 |
|---|---|---|---|
| P1-1 | **转写内置化** | `TranscriptionWorkflow.swift`(15 行)、`ScribeStudioIntegration.swift`(208 行) 目前只是 `NSWorkspace.open` 把文件交给外部 Electron App `dev.yuan.scribestudio` | 用户不该为了拿文稿去装第二个 App。把本地转写做进 NDM：下完自动出带时间戳的文稿+字幕，点一句跳到那一秒。本地推理，隐私干净 |
| P1-2 | **收件箱全文搜索** | 侧栏现在只按状态/类型/文件名搜 | 搜**内容**："我记得有个视频讲过 XXX" → 定位到那一秒。转写沉淀越多越离不开，这是留存护城河 |
| P1-3 | **章节与摘要卡片** | 完成页已有 Completion Stack | 长视频自动分章 + 一段摘要。成本低、感知强，且是目前产品**唯一可截图传播**的资产（现有设计哲学刻意安静，没有可传播画面） |
| P1-4 | **订阅追更** | 无 | 关注 UP 主/频道，新内容自动下。把工具变成服务，也是订阅制收费唯一站得住的锚点 |
| P1-5 | **Shortcuts / Raycast / CLI** | roadmap 已后置 | 对 Mac 极客口碑效率极高、成本低；Raycast 商店是免费传播渠道 |
| P1-6 | **投送到手机 / NAS** | 已有系统分享 | 下完直接进手机相册或 NAS。国内高频真实需求 |

### 明确不做

- AI 聊天助手界面（下载器不需要对话框）
- AI 猜链接 / 绕过站点权限（不可靠且踩反功能清单）
- AI 解释下载错误（`DownloadDiagnostic` 的规则文案已经更准更快，联网推理是净损失）
- AI 预测速度（无意义）

## 3. 每日循环协议

每轮执行：

1. 读本文件，选**最靠前的未阻塞**事项。一轮只做一件事，做完整。
2. 从当前工作分支切出 `loop/<日期>-<短名>`。
3. 实现 + 补测试。
4. 验收门禁：`swift build` 绿 · `swift test` 绿 · `extension/NDMRelay` 的 node 测试绿。
5. **自动合并条件**（全部满足才合）：门禁全绿；改动不涉及品牌命名、定价、购买 URL、许可证签名密钥；不删除或迁移用户数据路径。
6. **必须停下等审阅**的改动：纯视觉/布局调整（测试无法验收）→ 附 QA 截图；任何架构性重构；任何新增的联网行为。
7. 在下方进度日志追加一行：日期 · 事项 · 结论 · 是否已合并。
8. 报告要诚实：失败就贴失败输出，跳过就说跳过。
