## 1. 先做的产品决定

### 1.1 品牌命名

命名标准：好读好记、可注册域名、中英市场可用、不蹭竞品名。

候选方向：Downpour / Swoop / Pelican / Haul，以及中文副标。  
**当前工作名：Pelican**（设计稿已采用；理由：鹈鹕一口兜住大文件 = 多连接下载的天然隐喻，icon 潜力大，Mac 独立软件命名传统[动物名]，冲突集中在开发者工具而非消费级 App）。  
定名后再定 bundle id、官网、扩展商店名。

### 1.2 分发与商业边界

- 公开发行包只含本树产物（Swift 宿主 + 自有/MIT 扩展）。
- 断点格式、桥协议可按产品需要演进；对外叙事讲自有能力，不绑竞品品牌。

## 2. 差异化（付费理由）

> 本节全部功能的像素级设计与文案已定稿于 `design/NDM-Design-Suite.html`（含实施顺序与代码映射表）。

### 2.1 下载诊断

把引擎事件翻译成人话（任务行 / Inspector / 失败弹窗）：

- 链接过期 → 引导 Renew  
- 不支持 Range → 说明已切单连接  
- 多连接无收益 → 自动降连接并解释  
- 瓶颈在服务器 vs 本机网络  

### 2.2 智能连接数

从 2 起步，有收益再翻倍；全程可见「为什么是这个数」。

### 2.3 下完就是能播的 MP4

嗅探 → 选清晰度 → 下载 → 默认 remux 到 MP4（ffmpeg `-c copy`）。

### 2.4 Smart Finalize

命名、封面、成果成组与高频交付配方。默认不堆低清转码或聊天软件压缩预设。
