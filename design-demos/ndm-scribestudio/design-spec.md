# NDM × ScribeStudio · 三方向设计 Spec

## 项目本质

这不是两套彼此无关的“漂亮界面”，而是一套面向付费 Mac 用户的内容工具矩阵。NDM 负责把网页、视频、文档和普通文件可靠地取得到本地；ScribeStudio 接住视频或音频，完成转写、字幕、文本提取、校对和交付。用户可能从浏览器一键调用 NDM，也可能手动粘贴链接；下载完成后，应能在不重新寻找文件的情况下进入 ScribeStudio。设计既要让第一次使用的人不用读说明，又要让高频用户在长时间工作中感到快、稳、顺手。

## 目标受众与场景

- 经常下载课程、采访、素材、PDF 与安装包的 Mac 用户。
- 内容创作者、研究者、学生、播客与视频工作者。
- 需要一次处理多个任务、重试失败链接、比较清晰度或审阅字幕的高级用户。
- 典型环境是 13–16 英寸 MacBook 或外接显示器，键盘、鼠标/触控板并用，窗口可能与浏览器并排。

## 三版必须使用的真实内容

### NDM 代表屏

- 侧栏：全部、进行中、待继续、已完成、失败，以及视频/音频/文档等类型。
- 主列表至少包含一个进行中视频、一个已完成 DMG、一个链接过期任务；状态、来源、速度/大小必须一眼可扫。
- 右侧详情提供与状态有关的操作，已完成媒体要出现“在 ScribeStudio 中转写”，失败任务要出现“更新链接”，不能用笼统的“更换”。
- 顶部保留新建下载与搜索；主按钮不能产生上下叠影或多层背景。

### ScribeStudio 代表屏

- 接收到 NDM 下载的视频，显示真实文件名、封面/舞台、时码与转写进度。
- 提供语言、说话人分离、清理口水词等必要配方，但凭据和低频设置应后置。
- 逐段文本与视频/音频播放形成明确主次；输出格式不能五个同权重复选框挤在首屏。
- 接力来源要轻量表达“来自 NDM”，不能做成营销横幅。

## 情感基调

核心感受是“专业工具的安静自信”。它不是冷冰冰的企业后台，也不是堆满渐变、光晕、胶囊和 AI 口号的模板。允许有一处记忆点，但记忆点必须来自内容：NDM 用连续传输轨迹/任务流表达掌控；ScribeStudio 用时间轴与文本行的对应关系表达理解。色彩克制，状态色只承担状态；排印以中文为主，中英混排自然，不在每个标题上方重复 Source/Recipe/Preview 之类英文 kicker。

## 输出格式

- 设计探索类型：Mac 桌面 App 高保真 HTML 原型。
- 每个方向：1 个完整单文件 HTML，可双击打开并在 NDM/ScribeStudio/联动视图间切换。
- 截图统一：1440 × 900；设备像素比 1，方便同尺寸横向比较。
- 页面内使用 macOS 窗口框架与真实本地图标；不依赖网络字体或外部图片。

## 已知约束

- 方向确认前不修改两款真实产品 UI 源码，不创建 `direction-approved.md`。
- 三版必须使用不同布局骨架，不允许只换色。
- 正文不小于 14px，标签不小于 12px；数据用等宽数字。
- 禁止编造速度倍数、用户量、准确率、售价和折扣政策。
- 禁止无意义渐变背景、卡片套卡片、全页面胶囊、装饰 emoji、假 AI 星光与每个标题一个图标。
- NDM 的文件类型淡色背景/应用图标是用户刻意提出的识别设计，可以保留并做得更克制，不能被“去 slop”误删。

## 图片判断与策略

图片是内容必需：两款软件本身是数字产品，真实 UI 和真实图标必须作为设计依据。已取得两张当前聚焦窗口截图和两款当前图标；三版原型内的界面结构将从真实内容重构，不用营销 stock 图。视频缩略图只用抽象的本地色面占位，明确承担“媒体封面”功能，不伪造第三方视频内容。

## Form 推导五问

- 叙事角色：方向板同时承担设计比较与关键工作流演示，主角是“一个下载成果在两款 App 间继续流动”。
- 观众距离：主要在 1 米内的笔记本屏幕查看；需在 1440×900 截图中仍读得清。
- 视觉温度：专业、冷静、有少量温度；三方向分别偏编辑感、原生亲和、工业理性。
- 容量估算：一个方向板只展示两款软件各一个代表屏和一条接力动作，不塞全部设置。
- 视觉母题：同一个文件对象从 NDM 的任务行变成 ScribeStudio 的时间轴与文字段落；“连续性”是两款软件独有的共同结构。

## 三个物理隔离锚点

1. 秒数轮盘：30 秒 → `30 % 20 + 1 = 11` → 网页风格库第 11 项 Dark Editorial。结构锚点是固定深色工具轨 + 高密度编辑网格 + 单荧光强调。
2. 现实参照：2025 Apple Design Award Innovation 获奖 App Play。迁移“复杂能力仍然容易接近、模块组织清楚、原生工作流友好”，不复制其品牌外观。
3. 顶级设计思维：Dieter Rams / Braun 功能主义。采用少即是多、功能可见、物理仪器式分区、暖灰与信号橙；不做复古摆拍。
