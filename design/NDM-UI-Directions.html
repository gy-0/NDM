Huashu-Design · NDM

优雅的 Mac 下载工具 · 三个方向

不是复刻 Neat / FDM 的旧工具感，而是把「多连接、断点、浏览器接管」藏进成熟的 macOS 产品语言里。 下面三个方向来自不同设计流派，请选一个深化，或混搭（例如 B 的排版 + A 的侧栏）。

Assumptions（请拍板）
1. 品牌暂无正式 Logo → 用词标 NDM，后续可替换。
2. 能力基线保持：侧栏过滤、真实进度/速度/ETA、进度窗分段条、浏览器直开下载。
3. 默认浅色工作面；C 方向验证深色夜间工作台。
4. 主列表保持克制；连接级细节只在 Progress 窗。
5. 选定方向后，再落回 Swift AppKit（本页是设计源，不是生产代码）。

A · Quiet Finder

哲学锚点：Dieter Rams × Apple HIG 工具窗口——少装饰、高可读、像系统自带的下载管理。 适合「每天都开着」的工具：不抢戏，选中态清晰，进度是信息不是表演。

气质：克制 · 可信 · 系统 Accent：系统蓝 #2F6FED 字体：SF / IBM Plex
  • 侧栏 source list + 统一工具栏
  • 列表行：文件名 / 状态·主机 / 细进度条
  • 右侧 inspector 只留摘要动作
  • 进度窗：大号百分比 + 绿色分段条

推荐作为默认落地方向：和现有 Swift 结构最接近，改造成本最低，体感最「正统 Mac」。

主窗口 · 点击列表行可切换选中
进度窗口 · Segments 单色绿

B · Editorial Utility

哲学锚点：Information Architects（iA）× Newsreader 排版——把下载列表当成「正在阅读的任务」。 文件名用衬线建立层级，墨绿强调「完成/生长」，比仪表盘更安静、更有产品感。

气质：沉静 · 精致 · 人文 Accent：墨绿 #1F3D2A / 进度绿 #2F9E6B 字体：Newsreader + Plex
  • 选中用左侧竖线，而不是大色块
  • 卡片感更弱，靠分隔线与字号
  • 适合在意「品牌气质」的开源产品页截图
主窗口 · 衬线文件名
进度窗口 · 编辑感信息卡

C · Night Workshop

哲学锚点：Build Studio × 夜间工坊——深炭底 + 单一琥珀强调，服务「挂机下载 / 深夜赶工」。 避免赛博霓虹；暖色只出现在主按钮与活跃态，分段条仍保持功能绿。

气质：专注 · 成熟 · 夜间 Accent：琥珀 #D4A35C 底：Charcoal #1C1E22
  • 默认深色，适合菜单栏常驻工具
  • 信息密度略高但不堆卡片
  • 实现成本：需完整 Dark 令牌
