04下载诊断 — 把错误码翻译成人话（文案即产品）

这六张卡是写死进产品的文案资产，中英双语一次定稿。规则：第一句说发生了什么，第二句说为什么，按钮直接给出下一步。 永远不让用户面对裸的 403 / 416（原始码保留在角落供高手排查）。

链接已过期 HTTP 403

这个下载地址过期了

很多网站的下载链接只在签发后几分钟内有效。回到原网页，Pelican 会自动换取新地址并从断点继续。

This link has expired — sites often sign download URLs for only a few minutes. Reopen the page and we'll grab a fresh one, resuming where you left off.

已切换单连接 HTTP 416 / no Range

该服务器不支持分段下载

它不接受断点续传请求，多连接对它无效。已自动切换为单连接稳定下载——速度就是服务器给多少是多少。

This server doesn't support ranged requests, so multi-connection can't help here. Switched to a single steady connection.

瓶颈在服务器 throughput probe

你的网络没问题

本机带宽实测 480 Mbps，但该服务器每条连接只给约 2.1 MB/s。8 连接已榨到 ×6.9，这已是对方的上限。

Your connection measured 480 Mbps; the server serves ~2.1 MB/s per connection. Eight connections got us ×6.9 — that's the server's ceiling, not your Wi-Fi.

登录已失效 HTTP 401 / cookie

网站要求重新登录

保存的登录状态已过期。在浏览器里重新登录该网站后点「重试」，扩展会自动带上新的登录信息。

Your sign-in for this site expired. Log in again in your browser, then hit Retry — the extension passes fresh credentials automatically.

多连接无收益 auto-tuned to 1

已自动降为单连接

尝试了 8 条连接，总速度没有提升——该服务器对所有连接共享同一限速。已降回单连接，避免被误判为攻击。

Tried 8 connections; total speed didn't improve — this server pools all connections into one cap. Dropped back to 1 to stay polite.

建议 proxy heuristic

走代理可能更快

到该服务器的直连延迟 480 ms 且频繁丢包。检测到你配置过代理「HK-01」，用它下载这个站点通常会快很多。

Direct route to this host shows 480 ms latency with packet loss. Your saved proxy “HK-01” will likely be much faster for this site.

「同样快，但少十个让人骂的细节」的具体形态。每张卡对应引擎里一个已存在或可检测的事件，落地即 DiagnosticEvent → L10n key 的映射表。
